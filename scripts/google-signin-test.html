Google sign-in test harness

Performs a real Google OAuth round trip and hands back the Firebase ID token, so POST /api/v1/auth/social can be tested with sign_in_provider: google.com rather than a synthetic custom token.

Firebase web config
  1. Firebase Console → Project settings → General → Your apps → add a Web app if there isn't one (this project only has Android and iOS registered).
  2. Copy its apiKey below. The Android/iOS keys usually won't work here — they're restricted to their own apps.
